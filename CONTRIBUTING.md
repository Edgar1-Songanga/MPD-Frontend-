# Contributing to MAGESTADE PURA DIGITAL

## Code Style
- Use TypeScript
- Follow ESLint rules
- Format with Prettier
- Write tests

## Commit Messages
```
type(scope): description

Examples:
fix(workforce): correct employee update logic
feat(billing): add invoice generation
docs(api): update endpoint documentation
```

## Pull Request Process
1. Create feature branch
2. Make changes
3. Run tests: `pnpm test`
4. Lint code: `pnpm lint`
5. Create PR
6. Wait for reviews
